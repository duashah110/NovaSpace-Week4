# TechNova — Week 4: Performance & Accessibility

A responsive digital-solutions landing page enhanced for semantic structure, keyboard access, assistive technologies, and more efficient resource loading.

## Files
- `index.html` — semantic page structure, metadata, skip link, accessible controls and form labels.
- `style.css` — responsive styling, visible focus states, form feedback and reduced-motion support.
- `script.js` — accessible navigation, theme toggle, counters, FAQ accordion, form validation and back-to-top behavior.

## Run locally
Open `index.html` in a modern browser, or use the VS Code Live Server extension. No build tools or dependencies are required.

## Test
1. Use Tab / Shift+Tab to navigate and Enter / Space to activate controls.
2. Test at desktop and mobile widths using browser Developer Tools.
3. Run Chrome Lighthouse for Performance and Accessibility, then check with WAVE or axe DevTools. Record the actual results; no audit score is pre-filled.

## Note
The contact form performs front-end validation only; it does not send messages to a server.
